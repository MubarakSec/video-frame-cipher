# مختبر VFC التفاعلي

واجهة عربية واحدة تركز على المختبر التفاعلي. يشرح المختبر البصمة، واشتقاق المفاتيح، وجولات SPN، والانتشار، وCBC، والحمولة، وLSB.

القيم الثابتة في دروس البصمة والمفاتيح والجولات والقياسات تُولّد من تنفيذ Python بواسطة `../generate_vfc_trace.py`. أما «المحاكاة الكاملة» فتنفذ في TypeScript جولة مستقلة: ارفع نصاً أو ملفاً حقيقياً، شاهد حزمته وكتل CBC/SPN الفعلية، ثم تضمين في WAV مولّد أو ملف PCM 16-bit يختاره المستخدم، واستخراج وفحص وفك واسترجاع بعد إعادة تحميل الناتج.

لترتيب عرض الطلاب من الفيديو الحقيقي إلى شرح كل طبقة، اقرأ [دليل العرض العربي](../STUDENT_PRESENTATION_GUIDE_AR.md).

## التشغيل

```bash
cd /home/mobta/university/Crypto/academic-kit
npm install
npm run dev
```

افتح العنوان الذي يعرضه Vite. يفتح التطبيق المختبر مباشرة على `#lab`.

## العرض أمام المدرّس

1. ابدأ من «خريطة النظام» لتثبيت ترتيب الطبقات.
2. اضغط «ابدأ شرحاً موجّهاً».
3. استخدم «المحطة التالية» للانتقال بين ست محطات رئيسية.
4. افتح التفاصيل التقنية فقط عندما يسأل المدرّس عنها.

يمكنك أيضاً اختيار أي موضوع مباشرة من قائمة المختبر. يحفظ الرابط الموضوع الحالي في معامل `section` لتعود إليه بسرعة.

## التحقق قبل التسليم

```bash
npm run check
python3 -m vfc.tests  # من المجلد الأب
```

يشغّل `predev` و`prebuild` مولّد الأثر تلقائياً. ويضيف `npm run check` فحص توافق يثبت تطابق مفاتيح TypeScript والحزمة الداخلية والنص المشفر والحمولة والمواضع مع متجه Python، ثم يختبر تصدير WAV وإعادة تحميله والاسترجاع منه.

## الفرق بين الشاشتين

- الدروس تعرض متجه Python ثابتاً كي تبقى الأرقام نفسها أثناء الشرح.
- الاستديو يولّد ملحاً و`IV` جديدين وينفذ جولة كاملة على حامل WAV اصطناعي أو PCM 16-bit يختاره المستخدم.
